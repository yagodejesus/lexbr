# Como contribuir

Obrigado pelo interesse! Issues e pull requests são bem-vindos.

1. Faça um fork e crie uma branch: `git checkout -b minha-melhoria`
2. Instale em modo de desenvolvimento: `pip install -e ".[dev]"`
3. Escreva testes para a mudança em `tests/`
4. Rode `pytest && ruff check .` antes de abrir o PR

Ao relatar um problema, inclua um exemplo mínimo — **sempre com dados fictícios**, nunca com dados pessoais reais.
